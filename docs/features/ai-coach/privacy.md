# Privacy and consent

The pro-active coach, reminders, inference and memory are off by default. Manual planning remains usable without enabling automatic coaching. OS notification permission is requested only when the user explicitly saves enabled reminder preferences. Native delivery respects quiet hours, minimum intervals, coach enablement and the existing pause-reminders control. Disabled or unsupported notification delivery is never replaced by a toast presented as an OS reminder.

On-device coaching receives only a selected task title, selected starting difficulty, estimated effort and editable draft steps. It does not receive capture titles, URLs, screenshots or raw activity. There is no external network AI provider, diagnosis, psychological profile, productivity ranking or autonomous write/tool execution. Proposals require explicit user confirmation before storage.

Personalization may use only separately enabled preferences and visible, editable user-confirmed notes. Inferred patterns must be labeled as aggregate observations, never clinical conclusions. Session context is not an inference about motivation. No claims of GDPR certification are made; local storage is still personal data and users control its deletion.
